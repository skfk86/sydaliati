# صيدليتي السودان

تطبيق يربط المستخدمين بالصيدليات في السودان: الصيدليات المفتوحة القريبة، توفر الأدوية وأسعارها، الدردشة، والخرائط.

**الستاك:** ملف HTML واحد (`www/index.html`) + Capacitor 6 + Supabase (مشروع `sydaliati`).

## البناء
لا تحتاج تثبيت أي مكتبة على جهازك. كل المكتبات (Capacitor، Supabase، Leaflet) تُحمَّل داخل GitHub Actions
عبر `.github/workflows/android.yml`، ثم يُبنى ملف APK.

بعد كل `git push` إلى `main`: افتح تبويب **Actions ← آخر تشغيل ← Artifacts** وحمّل `sydaliati-debug-apk`.
ويمكنك تشغيله يدوياً من **Actions ← Build Android APK ← Run workflow**.

- الصيدلية لا تظهر للعملاء إلا بعد أن يوثّقها المشرف من **حسابي ← لوحة المشرف**.
